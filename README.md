# Weather
Decoded METAR: under the raw METAR text it shows flight category (colored), wind, visibility, weather, clouds, temperature, dew point and pressure, in both metric and imperial units.
	•	Decoded TAF: under the raw TAF text it shows the validity period, then each forecast period with its change type (From, Becoming, Temporarily, Probability), wind, visibility, weather, clouds and wind shear.
	•	Map: each airport card has an OpenStreetMap map at the top with the airport marked.
